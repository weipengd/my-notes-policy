XML Restore — Privacy Policy

Effective: November 17, 2026 · Applies to XML Restore v1.1.2

XML Restore is a Chrome extension for displaying XML documents, testing XSLT, inspecting XPath and exporting locally. The extension is designed to avoid collecting user content.

What is processed

XML Restore reads XML documents opened in your browser to display them as formatted source, a collapsible tree or a transformed result. It also processes the XML/XSLT text and files you enter in XSLT Studio locally on your device. JSON/CSV and HTML outputs are generated on your device.

Data sent from your device

XML Restore does not transmit your documents, stylesheets, XPath queries, parameters, account identifiers or browsing history to its developer. There is no developer-operated upload endpoint, analytics, ad tracking or cloud account.

When you expressly enter an HTTP(S) URL in XSLT Studio and choose Open, your browser requests the XML from that URL without sending your browser cookies. If a document references an XSLT file from the same website, the extension may also request that file from the website. The website you contact may receive ordinary network information such as your IP address. This is a direct request to the specified site, not an upload to XML Restore or a third-party analytics provider. Network downloads are limited to 4 MB and have a timeout.

Settings stored locally

Chrome's local extension storage holds the automatic viewer toggle and origins you individually enabled for optional XSLTProcessor API compatibility. Your browser's local web storage also saves interface preferences such as auto-run and whether the introductory help panel is dismissed. Neither storage area persists your XML or XSLT editor contents. You can delete this data by removing the extension or clearing its site storage.

Website permissions

HTTP and HTTPS access is needed for detecting XML pages, performing user-requested URL imports and fetching same-origin stylesheets. A small detection script runs on ordinary pages but does not extract form data. JavaScript XSLTProcessor API compatibility for ordinary HTML pages is enabled individually from the toolbar popup.

Security

Transformation results are previewed in a script-disabled sandbox. The parser rejects DTD/entity declarations and the standalone renderer rejects cross-origin stylesheet imports. The extension does not load remotely hosted executable code. Documents are limited to 4 MB for local processing.

Sharing and sale

We do not sell or share user data for advertising, profiling or marketing.

Chrome Web Store Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Website and document data are processed only to provide user-requested XML viewing and transformation features; they are not used for advertising, profiling, or unrelated purposes.

Updates and contact

If the extension's data handling changes materially, this privacy policy and Chrome Web Store disclosures will be updated first. Use the developer support contact shown on the official Chrome Web Store listing.
