Privacy Policy for My Simple Note

Last Updated: June 8, 2024

1. Data Collection

This Extension does not collect, store, or transmit any personally identifiable information (PII) to external servers.

2. Data Storage

All data recorded by the user (notes, code snippets) is stored locally within the user's browser using the chrome.storage.sync API. This data is synced across the user's own devices via their Google Account, as provided by the Google Chrome synchronization service.

3. Permissions Usage

  • Storage: Used to save and retrieve the user's notes.
  • ContextMenus: Used to allow the user to save selected text from websites directly into their notes.

4. Third-Party Access

We do not share any data with third parties. Your data remains under your control within your Google ecosystem.
